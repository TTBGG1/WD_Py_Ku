# 打飞机小游戏 (WD_Py_Ku)

一个用 Python + pygame 实现的经典「打飞机」飞机大战小游戏。

## 功能

- 🎮 键盘控制：`←` `→` 左右移动战机，`空格` 发射子弹
- 💥 击落敌机得分，敌机撞到你则损失生命（共 3 条命，受击后有短暂无敌保护）
- 📊 实时显示分数与生命
- 🔁 游戏结束按 `R` 重新开始

## 运行环境

- Python 3.8+
- pygame

## 安装与运行

```bash
# 安装依赖
pip install pygame

# 运行游戏
python main.py
```

## 文件结构

```
WD_Py_Ku/
├── main.py           # 游戏主程序
├── requirements.txt  # 依赖清单
└── .gitignore        # Git 忽略规则
```

## 玩法说明

- 用方向键控制底部绿色战机躲避红色敌机
- 按空格发射子弹，击落敌机每个 +10 分
- 生命归零游戏结束，按 `R` 重新开始
